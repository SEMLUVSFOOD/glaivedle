# Contributing

Thanks for wanting to help!

1. Fork and create a branch from `main`.
2. `pnpm install`, copy `.env.example` to `.env.local`, then `pnpm dev`.
3. Before opening a PR run `pnpm lint && pnpm typecheck && pnpm test && pnpm build`.
4. Add a line under **Unreleased** in `CHANGELOG.md`.
